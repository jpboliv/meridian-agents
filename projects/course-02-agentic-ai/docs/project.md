# Project goals

Draft for [issue 1](https://github.com/jpboliv/meridian-agents/issues/1).

The on-call engineer needs to decide whether to act, escalate, or close an incident. An earlier shift can narrow the search. Only evidence from the current incident can establish recovery.

The learning goal is to explain what reached the model, why the agent recalled a record, and when it refused a cached result. Choose a case for each decision and a comparison that can show when the policy fails.
